# Element and file reference (generated)

Generated by `uv run ilp schema` from the installed elements. Do not edit; re-run the command
after adding or changing an element. Paste this file into an LLM together with
`docs/LLM_AUTHORING_PROMPT.md`.

## Files

Every level is a YAML file. Keys marked `?` are optional.


### subject.yaml

- `id?` (string/null): Overrides the directory slug.
- `title` (string)
- `icon?` (string): Material icon ligature name.
- `description?` (string)
- `color?` (string/null): Optional Wavefront token name (e.g. 'primary'), never a raw colour.

### course.yaml

- `id?` (string/null)
- `title` (string)
- `description?` (string)
- `level?` (string)
- `tags?` (array)

### unit.yaml

- `id?` (string/null)
- `title` (string)
- `description?` (string)
- `requires?` (array/null): Unit ids in the same course that must be complete first. Default: the previous unit.

### <name>.lesson.yaml

- `id?` (string/null)
- `title` (string)
- `description?` (string)
- `xp?` (integer)
- `requires?` (array/null): Lesson ids ('lesson' in this unit or 'unit/lesson') that must be complete first. Default: the previous lesson in the unit.
- `arrange?` (string/null)
- `source?` (?/null)
- `items?` (array)
- `map?` (?/null)

An `arrange: auto` lesson supplies `source:` with `notes?` (markdown), `facts?` (list of `{term, definition, hint?}`) and `cloze?` (sentences with `{{answer}}` or `{{a|b}}` blanks); the platform generates the items. A manual lesson may include `- type: auto` (with `only?: [notes|facts|cloze]`) among its items to expand the source at that point.

- Every item has `type` and the fields below; `id` is optional but recommended (a unique slug
  inside the lesson). Unknown fields are errors.
- Fields marked `markdown` accept Markdown (bold, lists, fenced code, `$math$`); `markdown-inline`
  accepts inline Markdown only.
- `answer` indexes are 0-based. `___` in a `fill-blank` prompt is a blank; `answers` has one entry
  per blank (a string or a list of accepted alternatives), in order unless `ordered: false`.
- Validate with `uv run ilp validate <path>`; messages are `file:line: message`.
